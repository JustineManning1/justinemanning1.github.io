The analysis

Problem

Claim denials were treated as a billing-office problem to be appealed after the fact — expensive, slow, and only partially successful.

Approach

Classified denials by reason code and service line, traced 62% of surgical denials to missing prior auth, and moved the check upstream to scheduling.

Decision enabled

Surgical denials ran nearly double the other lines, and 62% traced to one reason: missing prior authorization. The March scheduling checklist cuts surgical denials by more than half.

Modeled impact: ~$3.2M/yr in first-pass revenue vs. appeal-and-rework costs

The SQL behind this view

These queries run against the raw CSV in this repo (load it into SQLite or DuckDB). The dashboard's aggregates are what these queries return.

SQL · Denial rate by service line and reasonSQLite / DuckDB
SELECT service_line, denial_reason,
       COUNT(*) AS denied_claims,
       ROUND(100.0 * COUNT(*) / SUM(COUNT(*)) OVER
             (PARTITION BY service_line), 1) AS pct_of_line_denials,
       ROUND(SUM(charges_usd), 0) AS charges_at_risk
FROM hospital_encounters
WHERE claim_denied = 1
GROUP BY service_line, denial_reason
ORDER BY service_line, denied_claims DESC;
SQL · Recovered revenue after the checklistSQLite / DuckDB
WITH monthly AS (
  SELECT service_line, strftime('%Y-%m', discharge_date) AS month,
         AVG(claim_denied * 1.0) AS denial_rate,
         SUM(charges_usd) AS charges
  FROM hospital_encounters GROUP BY 1, 2)
SELECT month,
       ROUND(100 * denial_rate, 1) AS denial_pct,
       ROUND(charges * (0.145 - denial_rate), 0) AS est_revenue_recovered
FROM monthly
WHERE service_line = 'Surgical' AND month >= '2026-03';

The Power BI translation

The same model expressed as DAX measures — how this dashboard is built when the delivery target is Power BI instead of the web.

Power BI · Denial rate measureDAX
Denial % =
DIVIDE (
    CALCULATE ( COUNTROWS ( Enc ), Enc[claim_denied] = 1 ),
    COUNTROWS ( Enc )
) * 100
Power BI · Charges at riskDAX
Charges At Risk =
CALCULATE (
    SUM ( Enc[charges_usd] ),
    Enc[claim_denied] = 1,
    Enc[denial_reason] = "Missing prior auth"
)
